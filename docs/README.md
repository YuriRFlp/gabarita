## Convenções desta documentação

- A documentação evolui junto com o código: toda mudança de schema ou de regra atualiza o documento correspondente e o `CHANGELOG.md`.
- Decisões que têm alternativas razoáveis viram um ADR em `docs/adr/`, numerado e nunca apagado (se mudar, cria-se um novo ADR que substitui o anterior).
- Fatos tirados de editais citam o edital de origem.
